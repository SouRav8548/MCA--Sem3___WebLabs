Create a web application using PHP, HTML, CSS, Java Script on XAMPP that includes the following features:

1. A calculator with two modes: basic arithmetic operations (addition, subtraction, multiplication, division, Reminder) and scientific functions (trigonometry, logarithms, exponents), with a toggle switch to switch between modes.

2. A multi-unit converter supporting currency, weight, and length conversions, number system conversion, featuring an intuitive user interface.

3. A secure user authentication system including sign-up and login pages connected to a database. The sign-up form should require email verification, password input with strength validation. Implement session management with configurable session timeout and persistent login.

4. After successful login, users should have access to all calculator and converter functionalities.

5. A user profile section allowing users to view and update their personal information.

6. The entire application should feature a modern blue and black color theme by default, with a toggle button in the navigation bar enabling users to switch between light mode and dark mode seamlessly.

Ensure the application is based on White and Green theme also responsive, user-friendly, secure against common vulnerabilities, and includes clear error handling and validation throughout.
